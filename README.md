# 자람원예치료연구소 · JARAM

자람원예치료연구소 공식 소개용 정적 웹사이트입니다. GitHub Pages 배포에 맞춰 HTML/CSS/Vanilla JavaScript로 구현했습니다.

## 사이트

- GitHub Pages 주소: https://jungsuplee-hub.github.io/jaram_miri/
- 인스타그램: https://www.instagram.com/jaram_miri/
- 프로그램 문의: https://business.inpock.co.kr/form?partner=ymr13

## 수정 안내

- 페이지 내용: `index.html`
- 반응형 스타일: `styles.css`
- 모바일 메뉴 및 스크롤 애니메이션: `script.js`
- 이미지 출처: `credits.html`
- 사진 파일: `assets/`

공개 인스타그램 프로필 및 출판사의 『행복 자람 원예교실』 자료를 참고했습니다.
실제 연구소 활동 사진을 제공받지 못해 Pexels 스톡 사진을 **연출 이미지**로 표시했습니다.
도서 소개에는 알라딘의 실제 표지를 축소해 표시하고 출처를 안내합니다.

## GitHub Pages

`main` 브랜치의 저장소 루트 (`/root`)를 게시 소스로 사용합니다. 정적 페이지이므로 서버나 빌드 도구가 필요 없습니다.
