## 인스타그램 활동 갤러리 (2026-11-21 업데이트)

공식 프로필의 공개 임베드 페이지에서 접근 가능한 **최근 6개 게시물 / 사진 10장**을 원본 게시글의 사진 및 설명과 함께 저장했습니다. 전체 인스타그램 게시물 2,471개를 수집한 것은 아닙니다. 비공개 데이터나 과거 기록을 임의로 채우지 않습니다.

- 화면에는 처음 4개 활동만 표시하며 **전체 활동 보기**를 누르면 현재 수집된 6개를 표시합니다.
- 활동 사진을 클릭하면 사이트 내부 팝업이 열리고, 여러 장의 사진 탐색과 원본 게시글 전체 설명이 가능합니다.
- 원예키트 / 연구소 소개 / 사진 섹션의 모든 활동 사진도 같은 팝업을 엽니다.
- 출처와 수록 게시물 목록: `data/gallery.json`. 새 자료를 추가할 때는 갤러리 데이터와 HTML 카드 및 `photo-gallery-data` JSON을 함께 갱신해야 합니다.
- 이미지 자산: `assets/instagram/*-gallery.jpg` 로컬 최적화 JPEG. 불러오지 못할 때 1회 재시도 및 오류 메시지 제공.
- 모바일: 카드 1열, 전체 화면 사진 팝업, 이전·다음 버튼, 터치 스와이프, ESC 및 닫기 지원.

전체 아카이브를 추가하려면 계정 소유자가 공식 Instagram 데이터 내보내기 파일을 제공해야 합니다.
