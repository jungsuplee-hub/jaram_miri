## 검증된 활동 사진 갤러리와 프로그램별 전체보기

2026-11-21 기준 공개 미러 [ins.ninja @jaram_miri](https://ins.ninja/@jaram_miri)에서 대표 이미지·날짜·본문이 노출된 **2,470개 게시물(2018~2026)** 을 화면 스크롤로 확인했습니다. 인스타그램 자체 프로필의 게시물 표기 수와 1건 차이가 있으므로 **계정 전체 자료를 빠짐없이 확보했다고 주장하지 않습니다.** 비공개 자료를 포함한 완전한 아카이브는 본인 공식 데이터 내보내기가 필요합니다.

현장 프로그램의 대상·수업 내용이 실제 게시글에 명시된 사진을 직접 확인하여 **227개 사례/230장**의 대표 이미지를 선별했습니다. 개인 일상, 가족사진, 무관한 교육·연수, 학교 수업, 모집 포스터, 공지, 사진만으로 목적을 확인할 수 없는 소재 등은 갤러리에서 제외했습니다.

- 홈 갤러리: 4건만 최초 표시하고 `4개 더보기`를 누를 때마다 정확히 4건씩 추가 표시
- 별도 전체보기: [`activities.html`](activities.html)에서 대상·프로그램별로 분리 (장애인 원예치료, 어르신 돌봄, 치매·인지지원, 어르신 원예활동, 직장인 정서지원, 기타 원예치료)
- 전체보기 프로그램 필터 + 연도 선택을 동시에 적용, 건수 자동 반영
- 사이트 내 사진 팝업 및 인스타그램 원문 링크
- 갤러리 원본 데이터는 `data/gallery.json`, 게시물 원문 URL과 현장별 제목·날짜·이미지 경로 보존
- 갤러리 수정 시 `python3 scripts/render_gallery.py` 실행하여 홈/전체보기 동시 갱신
- 공개 웹페이지와 이미지는 언제든지 삭제되거나 수정될 수 있으므로 대외 게시 전 사진 사용권과 참여자 초상권 확인 권장
