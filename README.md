## 인스타그램 활동 갤러리 (2026-11-21 업데이트)

2026-11-21 기준 공식 인스타그램 프로필 임베드 페이지에서는 최근 게시물 6개를 확보했습니다. 이후 공개 Instagram 열람 사이트 [ins.ninja의 @jaram_miri 프로필](https://ins.ninja/@jaram_miri)에서 'Load more'를 4회 사용해 **서로 다른 게시물 60개**의 날짜·본문·대표 이미지를 확인했습니다.

해당 60개를 검토해 개인 가족 일상 및 불완전한 이미지를 제외하고 **34개 활동·게시물, 실제 사진 37장**을 홈페이지 갤러리에 적용했습니다. 2024~2026년 원예치료, 초등 원예수업, 대학 특강, 복지원예사 전문가 양성, 치매안심센터·노인복지관 프로그램, 치유농업 지원사업 등의 게시물이 포함됩니다.

- 화면에 **처음 4개**만 표시하고, **전체 활동 보기**에서 현재 선정한 34개를 펼칩니다.
- 사진 클릭 시 **홈페이지 내부 팝업**에서 사진과 소개 문구를 볼 수 있습니다. 인스타그램 사이트로 강제 이동하지 않습니다.
- 사진 파일은 `assets/instagram/`에 최적화하여 로컬 저장했습니다. 사진 원본 링크는 `data/gallery.json`의 `source` 필드로 유지합니다.
- 최초 6개는 원본 게시물에 포함된 여러 사진까지 저장했으며, 새로 추가한 29개에는 **대표 이미지 1장씩**을 넣었습니다. 전체 게시물의 모든 사진·영상까지 확보한 것은 아닙니다.
- 데이터 파일 `data/gallery.json`을 수정한 후 `python3 scripts/render_gallery.py`를 실행하면 홈페이지 활동 카드와 팝업 데이터가 동기화됩니다.
- 모바일: 반응형 카드, 전체 화면 팝업, 다중 사진 넘기기·스와이프, 닫기 기능을 지원합니다.

**수집 범위 주의:** 인스타그램 계정의 전체 2,471개 게시물을 수집한 것은 아닙니다. 외부 공개 뷰어의 추가 페이지 제공 여부와 개별 이미지 접근이 변할 수 있으므로, 자료 전체의 완전성 확보에는 계정 소유자의 공식 데이터 내보내기 자료가 가장 신뢰할 만합니다.
