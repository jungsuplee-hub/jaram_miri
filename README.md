## 인스타그램 실제 원예치료 활동 갤러리

2026-11-21 공개 사이트 [ins.ninja @jaram_miri](https://ins.ninja/@jaram_miri)에서 날짜·본문·대표 이미지가 있는 기록 **1,032개(2021~2026)** 를 확인했습니다. 2024~2026 게시물에 대해서는 `Instagram` 공식 공개 임베드에서도 최근 6개의 원본 게시물을 확인했습니다.

이 중 **현장 사진을 직접 검토한 142개 활동 게시물 / 145장의 실제 활동 이미지**를 갤러리에 적용했습니다. **공부·전문가 양성과정 사진, 학교 수업 사진, 모집 포스터, 가족 사진, 단순 꽃 클로즈업이나 맥락이 불분명한 이미지는 제외**했습니다. 활동 갤러리의 주제는 복지기관·장애인주간보호센터·치매안심센터·어르신 돌봄 활동입니다.

- 처음 4개만 표시, 전체 활동 보기로 나머지 펼침
- 연도별 분류 버튼으로 원하는 연도 활동만 확인
- 모든 활동 사진은 로컬 `assets/instagram/` 이미지와 사이트 자체 팝업을 사용
- 모바일 연도 필터는 가로 스크롤, 활동 사진은 전체화면 팝업
- `data/gallery.json`에 활동별 날짜, 간단한 소개, 사진 경로, 실제 게시물 원문 링크 보존
- 원본 갤러리 데이터 수정 시 `python3 scripts/render_gallery.py` 실행

전체 계정 게시물 2,471개를 수집한 것이 아닙니다. 비공개 자료나 사진이 불확실한 게시물은 추가하지 않았습니다.
